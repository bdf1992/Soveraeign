# Naming Record

The owner-selected product and repository handle is **Soveraeign**.

This selection closes the repository naming question. It does not by itself
complete trademark, package, domain, or adjacent-product screening, and it does
not assert that the product has passed Phase-I operational qualification.

## Naming brief

A candidate must carry, without lengthy explanation:

- enterprise operation rather than knowledge storage alone;
- algorithmic governance without implying automated domination;
- native participation by humans and models;
- local custody and inspectability;
- action, authority, evidence, and consequence;
- growth from experience rather than preloaded omniscience;
- future federation without cloud dependence;
- and enough linguistic and legal distinctiveness to own.

## Remaining process

1. Preserve Bdo's selection and its exact spelling: `Soveraeign`.
2. Run current repository, domain, package, product, and trademark collision
   screening before public release.
3. Run cold-reader tests: ask what the name appears to make without supplying
   the system description first.
4. Record objections and failure modes, not only favorable associations.
5. If the owner changes or strikes the name, land a new decision and update all
   authoritative references atomically.

No agent may reinterpret, normalize, or respell the selected name by
convenience.
