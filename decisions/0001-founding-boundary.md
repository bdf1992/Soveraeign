# 0001 · Founding boundary

Status: `PROPOSED FOR BDO RATIFICATION`

## Decision

The project is constituted as a locally sovereign, algorithmic, AI-native
enterprise operating environment: one governed record and runtime used by human
and model operators under shared transition semantics.

The new repository is a clean founding line. Previous repositories are
ancestors and evidence, not an inherited implementation base.

## Consequences

- The repository starts with constitution, lineage, conformance, and phased
  product requirements.
- Production runtime code waits for the logical specification and defeating
  fixtures.
- Existing enterprise applications may later be bound through adapters.
- The first real workflow will test whether this is the enterprise environment
  itself or a governing operational layer over other applications.

## Rejected defaults

- merging all predecessor code;
- selecting one previous repository as the implicit kernel;
- treating the Gauge or Definition Object as the whole product;
- selecting a stack before logical closure;
- naming the product from its substrate alone.
