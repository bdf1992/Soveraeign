## What running the wave found

1. **Worktrees cut one commit behind.** The isolation worktrees were based on `4b0bc1d`, not the
   branch tip, so no worker held the report or the export its contract cited. Corrected by message;
   lane D materialised the export as an input. A launch that cannot say which revision it works on
   is fizzle 5 again, one level up.
2. **Helper lease ids collide.** A helper lease's id derives from parent plus reference, so the
   witness lease recruited on the same reference as the worker's took the same id and superseded it.
   Two helpers on one reference cannot both be held. The lease record for each worker is therefore
   the witness's; the lane's worker is attested by its report and its witness, not by a lease.
3. **The lanes were not journaled.** Nothing appended `ATTEMPTED` when a worker launched, because
   the launcher is the host's agent tool and not a kernel transition. The thin circuit journaled by
   hand; three lanes at once did not. A `take` that appends the attempt is the missing primitive.
4. **A session reads as gone between commands.** Each shell command is a new process, so the
   registry reported `SESSION GONE` until a heartbeat. Live means heartbeat, not presence.
5. **Nested worktrees break tree-walking checks.** With three worktrees under `.claude/worktrees/`,
   a tooling test walked their copies of `decisions/` and the shard crossed its ceiling. Verify on
   the shared tree was unreliable while lanes were open; every landed tip was verified in a fresh
   clone instead, and each passed 50 of 50.
6. **Landing rebuilds are the controller's, and they are more than docs.** Lane D's manifest edit
   staled the capability map, the Node Interface projection and the surface page; the builder's
   contract withheld those rebuilds and the witness found the red. The ordered set is: capability
   map, interface projection, surface page, docs page, clarity receipts.
7. **The observed bytes of the thin circuit are not the committed bytes for two files.** Lane D's
   worker found that the second observation's digests for `docs/documentation.html` and
   `.clarity/coverage.json` match no commit, because both were rebuilt after settlement and before
   the commit (report added, counts bumped). Settle, then land the exact settled bytes, or observe
   after the derived files are final. Recorded here; the thin circuit's export is left as it is.
8. **Landed bytes can differ from witnessed bytes by merge.** Lane D's `KNOWN-GAPS.md` merged with
   the thin circuit's R13 rows on landing; seven of eight witnessed files landed byte-identical, the
   eighth got a scoped third pass.
